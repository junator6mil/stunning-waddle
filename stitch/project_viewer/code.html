About this Space

The Lumina Penthouse project explores the intersection of brutalist architecture and organic interior lighting. Designed using real-time path tracing, this space features floor-to-ceiling smart glass that adapts its opacity based on the sun's trajectory.

Every material in this 3D model is physically accurate, from the brushed obsidian floors to the woven silk acoustic panels. This tour allows you to manipulate light sources and explore the atmospheric shifts throughout a simulated 24-hour cycle.
